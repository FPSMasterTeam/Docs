# 开始使用

FPSMaster 目前有两个可供玩家下载的客户端：Edge 和 Nova。先根据你玩的 Minecraft 版本选一个：

- 玩 1.8.9，选 [Edge](/guide/edge)，它基于 Forge。
- 玩 1.19.2 及以上的现代版本，选 [Nova](/guide/nova)，它基于 Fabric。

选好之后，先安装对应的加载器（Forge 或 Fabric），再从官网、Modrinth 或 CurseForge 安装客户端本体。

如果不想手动装加载器，也可以直接用 [FPSMaster 启动器](/guide/launcher)，由它处理下载、安装和启动。
