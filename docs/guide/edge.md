# Edge

FPSMaster Edge 是面向 Minecraft 1.8.9 的客户端，以 Forge 模组形式发布。当前版本 1.0.2-beta，处于 beta 阶段。

Edge 采用 GPL-3.0 许可证，这一点和 Nova（MIT）不同，详见[许可证](/about/licenses)。源码在 [fpsmaster-edge](https://github.com/FPSMasterTeam/fpsmaster-edge)。想参与开发，见[构建 Edge](/dev/edge)。

## 下载

任选一个渠道：

- [官网](https://fpsmaster.top)
- [Modrinth](https://modrinth.com/mod/fpsmaster)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/fpsmaster)

也可以直接用 [FPSMaster 启动器](/guide/launcher)，它自带 Edge 预设实例，不用手动装。

## 手动安装

1. 安装 Forge 1.8.9。从 Forge 官网下载 1.8.9 的安装器，运行并选择「Install client」。
2. 下载 Edge 的 jar 文件。
3. 把 jar 放进 `.minecraft/mods` 文件夹。
4. 用 Forge 1.8.9 配置启动游戏。1.8.9 请用 Java 8 运行，版本太老或太新都可能出问题。

启动后看到 Edge 的主菜单，说明装好了。

## 首次启动引导

第一次启动 Edge 会进入游戏内引导，跟着走完即可：

1. 选语言和界面缩放。
2. 看一段基础教程和功能介绍。
3. 登录 FPSMaster 账号。这一步可以跳过，不影响游玩。
4. 在「选项」页决定两件事：是否开启客户端反作弊（在支持的服务器上获得受信任标识），是否允许上传匿名数据。
5. 可选的偏好问答。按你的回答预先开启一批模块并设置背景。

左下角可以跳过整个引导。匿名数据的说明见[下文](#匿名使用数据)。

## 基本操作

| 操作 | 默认按键 |
| --- | --- |
| 打开客户端设置界面 | 右 Shift |
| 按住缩放视野 | 左 Ctrl |
| 聊天栏命令前缀 | `.` |

这些都能在设置界面的「客户端设置」里改。

调整 HUD 布局：打开聊天栏，拖动组件换位置，滚轮调大小。

## 模块

Edge 的功能以「模块」组织，分四类：优化、视觉、实用、界面。在设置界面里按分类浏览，点击开关，进入模块面板调整选项。

### 优化

帮你把帧数和操作手感调顺。

| 模块 | 用途 |
| --- | --- |
| 性能 | 一组帧数优化开关：快速渲染、粒子限制、实体裁剪、限制区块加载、隐藏干扰物等，按需打开 |
| 旧动画 | 恢复旧版风格的挥手、格挡等动作 |
| 缩放 | 让缩放视野的过程平滑，支持滚轮调倍率 |
| 没有受伤动画 | 移除受伤时的视角摇晃 |
| 无打击延迟 | 取消击空后的点击延迟 |
| 固定物品栏 | 取消药水效果对物品栏位置的影响 |
| 更好的鱼竿 | 调整钓鱼竿的显示，如线的宽度 |

## 命令

在聊天栏输入，以 `.` 开头。常用命令：

- `.help`：列出全部命令。`.help <命令>` 查看某个命令的用法。
- `.toggle <模块>`：开关模块。
- `.set <模块> <选项> <值>`：修改模块选项。
- `.bind <模块> <按键|none>`：给模块绑定快捷键。
- `.config save|load|list [名称]`：保存、加载、查看配置。
- `.replay`：打开回放界面。`.replay start [名称]` 开始录制，`.replay stop` 停止。
- `.telemetry`：查看匿名数据开关的当前状态。

命令前缀可以在客户端设置里改。

## 录像与回放

开启录像模块后，可以录制对局并回放：

1. 进入世界。
2. 输入 `.replay start` 开始录制，或从回放界面操作。
3. 输入 `.replay stop` 停止。文件保存在 `.minecraft/FPSMaster Edge/replays` 文件夹，扩展名 `.edgereplay`。
4. 从主菜单的「回放」进入，播放、重命名或删除录像。

回放内置剪辑工具，可以打关键帧做运镜，导出 MP4。导出的文件在 `.minecraft/FPSMaster Edge/exports`，需要系统里装有 ffmpeg。

## 配置方案

当前配置会自动保存。想保留多套配置：

1. 打开主菜单或设置界面里的「配置」入口。
2. 新建配置并命名。
3. 点击配置卡片即可切换。

配置支持导入和导出，文件在 `.minecraft/FPSMaster Edge/config` 文件夹，方便分享给朋友。

## 账号

主菜单支持添加微软账号或离线账号，可以在游戏内切换。另外可以登录 FPSMaster 账号，用于饰品等联网功能，不登录不影响正常游玩。

## 匿名使用数据

Edge 默认会发送匿名使用数据，用于改进客户端，不包含明文账号信息。

- 开关在首次启动引导的「选项」页，之后没有游戏内开关。
- `.telemetry` 命令只能查看当前状态，不能开关。
