# Nova

FPSMaster Nova 是基于 Fabric 的多版本客户端，目前处于 beta 阶段。

支持的 Minecraft 版本：1.19.2、1.20.1、1.21.1、1.21.8、1.21.11。另有 26.2 的构建目标，部分能力还在适配中。

已知限制：

- Linux 尚未测试。
- 不支持 Intel 核显。
- 不支持 Android。

Nova 采用 MIT 许可证，源码在 [fpsmaster-nova](https://github.com/FPSMasterTeam/fpsmaster-nova)。想参与开发，见[构建 Nova](/dev/nova)。
