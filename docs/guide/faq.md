# 常见问题

## Edge 和 Nova 怎么选

按你玩的 Minecraft 版本选：1.8.9 用 Edge（Forge），1.19.2 及以上的现代版本用 Nova（Fabric）。两个客户端相互独立，可以都装。

## 从哪里下载

从官网、Modrinth 或 CurseForge 下载客户端本体，或者直接用[启动器](/guide/launcher)安装。不要从来路不明的站点下载重新打包的版本。

## Edge 和 Nova 的许可证为什么不一样

Edge 采用 GPL-3.0，Nova 采用 MIT，这是两个仓库各自的选择。如果你要基于源码做二次开发或分发，先确认对应仓库的条款，细节见[许可证](/about/licenses)。
