## 使用时要做什么

### GPL-3.0

Edge 使用 GPL-3.0。分发修改版或基于该代码形成的衍生作品时，需要按 GPL-3.0 提供对应源代码、许可证文本和版权声明。不要将 Edge 源码直接复制到不兼容许可证的项目。

### LGPL-2.1

mcef-nova 使用 LGPL-2.1。通过库边界使用时，宿主可以采用其他许可证；分发时仍需保留 LGPL 文本，并满足用户替换或重新链接该库的条件。修改 mcef-nova 本身后再分发，需要提供这些修改的源码。

### MIT

Nova、启动器、Prism、Cadence 和 Extreme 使用 MIT。复制或分发软件及其主要部分时，保留版权声明和 MIT 许可文本。

### Apache-2.0

本文档站使用 Apache-2.0。复制或修改文档时，保留许可证与适用的版权、NOTICE 声明。Apache-2.0 还包含专利许可和专利终止条款。

## 第三方依赖

仓库许可证不自动覆盖第三方库、字体、图片、Minecraft 资源或 CEF/JCEF 组件。发布产物前检查依赖清单和资源来源，按各自条款保留声明。

本页是工程使用摘要，不构成法律意见。发生冲突时，以仓库中的完整许可证文本和适用法律为准。
