# 许可证

FPSMaster 各仓库的许可证并不统一，使用或分发前请确认对应仓库的条款。

| 项目 | 仓库 | 许可证 |
| --- | --- | --- |
| Edge | [fpsmaster-edge](https://github.com/FPSMasterTeam/fpsmaster-edge) | GPL-3.0 |
| Nova | [fpsmaster-nova](https://github.com/FPSMasterTeam/fpsmaster-nova) | MIT |
| 启动器 | [fpsmaster-launcher](https://github.com/FPSMasterTeam/fpsmaster-launcher) | MIT |
| Prism | [fpsmaster-prism](https://github.com/FPSMasterTeam/fpsmaster-prism) | MIT |
| Cadence | [cadence](https://github.com/FPSMasterTeam/cadence) | MIT |
| Extreme | [fpsmaster-extreme](https://github.com/FPSMasterTeam/fpsmaster-extreme) | MIT |
| mcef-nova | [mcef-nova](https://github.com/FPSMasterTeam/mcef-nova) | LGPL-2.1 |
| 本文档站 | [Docs](https://github.com/FPSMasterTeam/Docs) | Apache-2.0 |

几点常见的影响：

- Edge 是 GPL-3.0：基于 Edge 源码的二次分发必须以相同许可证开源。
- mcef-nova 是 LGPL-2.1：以库的方式链接使用时，你自己的代码不必开源，但对库本身的修改需要开源。
- 其余 MIT 仓库只要求保留版权与许可声明。

以上是简述，不构成法律意见，准确条款以各仓库内的 LICENSE 文件为准。
