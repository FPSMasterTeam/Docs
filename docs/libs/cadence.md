# Cadence

Cadence 是一个 JVM 库（Maven 坐标 `top.fpsmaster:music-api`），提供网易云音乐和 QQ 音乐的数据访问：搜索、播放直链、歌词、歌单、二维码登录等。

它只取数据，不播放、不带界面。拿到播放直链后，交给你自己的音频播放器解码。

兼容 Java 8，除 Gson 外没有第三方依赖，可用于任何 JVM 项目，包括 Minecraft mod。

当前版本是 v0.1.1。Cadence 采用 MIT 许可证，源码在 [cadence](https://github.com/FPSMasterTeam/cadence)。
