# 开发者

FPSMaster 的代码分布在多个仓库，按用途和许可证各自独立。当前的仓库一览：

| 仓库 | 内容 | 许可证 |
| --- | --- | --- |
| [fpsmaster-edge](https://github.com/FPSMasterTeam/fpsmaster-edge) | Minecraft 1.8.9 · Forge 客户端（beta） | GPL-3.0 |
| [fpsmaster-nova](https://github.com/FPSMasterTeam/fpsmaster-nova) | Fabric 多版本客户端（beta） | MIT |
| [fpsmaster-launcher](https://github.com/FPSMasterTeam/fpsmaster-launcher) | 跨平台桌面启动器 | MIT |
| [fpsmaster-prism](https://github.com/FPSMasterTeam/fpsmaster-prism) | immediate-mode UI 脚手架库 | MIT |
| [cadence](https://github.com/FPSMasterTeam/cadence) | 网易云 / QQ 音乐数据客户端库 | MIT |
| [mcef-nova](https://github.com/FPSMasterTeam/mcef-nova) | Nova 使用的嵌入式浏览器组件 | LGPL-2.1 |
| [fpsmaster-extreme](https://github.com/FPSMasterTeam/fpsmaster-extreme) | Rust 重写实验，非产品 | MIT |
| [Docs](https://github.com/FPSMasterTeam/Docs) | 本文档站 | Apache-2.0 |

想提交代码，先读[参与贡献](/dev/contributing)；构建客户端见[构建 Edge](/dev/edge)与[构建 Nova](/dev/nova)。
